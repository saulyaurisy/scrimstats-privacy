Política de Privacidad de ScrimStats Bot

Última actualización: 18 de agosto de 2026

Esta Política de Privacidad explica cómo ScrimStats Bot procesa la información cuando se utiliza dentro de servidores de Discord.

ScrimStats Bot es una herramienta destinada a la gestión de scrims y al procesamiento de estadísticas de partidas competitivas de Free Fire.

1. Información que procesa ScrimStats

Para proporcionar sus funciones, ScrimStats puede procesar información contenida en archivos de registro (.log) que los usuarios adjuntan a mensajes dentro de Discord.

Estos archivos pueden contener información relacionada con las partidas, incluyendo, entre otros:

  • Información de jugadores.
  • Nombres o identificadores utilizados dentro de las partidas.
  • Información de equipos.
  • Eliminaciones.
  • Posiciones.
  • Resultados de las partidas.
  • Otros datos necesarios para calcular estadísticas y puntuaciones.

ScrimStats utiliza esta información únicamente para procesar los resultados y proporcionar sus funciones de estadísticas y gestión de scrims.

2. Contenido de los mensajes de Discord

ScrimStats utiliza el acceso al contenido de mensajes necesario para detectar mensajes que contienen archivos de registro (.log) utilizados por el sistema.

El bot no está diseñado para analizar conversaciones personales ni para recopilar de forma general el contenido de las conversaciones de los servidores.

Importante: ScrimStats necesita procesar el contenido de los archivos de registro enviados mediante Discord para poder generar las estadísticas de las partidas.

3. Almacenamiento de información

La versión actual de ScrimStats procesa la información de las partidas durante la ejecución del bot y mantiene los datos procesados temporalmente en memoria.

La versión actual del bot no utiliza una base de datos externa para almacenar permanentemente el contenido de los mensajes o los archivos de registro procesados.

Los archivos de registro son utilizados como entrada para el procesamiento de las estadísticas y no son utilizados por ScrimStats para crear una base de datos permanente de conversaciones de Discord.

4. Uso de los datos

La información procesada se utiliza para:

  • Procesar resultados de partidas.
  • Calcular estadísticas.
  • Procesar eliminaciones y posiciones.
  • Generar resultados de scrims.
  • Generar estadísticas de jugadores y equipos.
  • Proporcionar las funciones relacionadas con la competición.

5. Inteligencia artificial

ScrimStats no utiliza el contenido de los mensajes ni los archivos de registro procesados para entrenar modelos de inteligencia artificial o modelos de aprendizaje automático.

6. Publicidad y venta de información

ScrimStats no utiliza la información procesada para publicidad personalizada y no vende el contenido procesado a terceros.

7. Compartición de información

ScrimStats no comparte deliberadamente el contenido de los archivos de registro con terceros para fines comerciales.

Las estadísticas y resultados generados por el bot pueden ser mostrados dentro del servidor de Discord en el que se utiliza ScrimStats, dependiendo de la configuración y las funciones utilizadas por los administradores del servidor.

8. Discord

ScrimStats funciona como una aplicación de terceros dentro de Discord. El uso de Discord también está sujeto a las políticas, condiciones y prácticas de privacidad de Discord.

ScrimStats no controla las políticas de privacidad de Discord ni las prácticas de otros servicios utilizados por Discord.

9. Seguridad

Se aplican medidas razonables para limitar el acceso a la información procesada por el bot y utilizarla únicamente para las funciones para las que fue diseñado.

Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

10. Cambios en esta Política de Privacidad

Esta Política de Privacidad puede actualizarse cuando se introduzcan nuevas funciones, cambios técnicos o modificaciones en la forma en que ScrimStats procesa información.

Cuando se realicen cambios importantes, se actualizará la fecha de "Última actualización" indicada al comienzo de esta página.

11. Contacto

Si tienes preguntas relacionadas con esta Política de Privacidad o con el funcionamiento de ScrimStats, puedes contactar al administrador o propietario de ScrimStats a través del servidor de Discord donde se encuentre instalado el bot.

12. Aceptación

Al utilizar ScrimStats Bot, reconoces que has tenido la oportunidad de consultar esta Política de Privacidad y comprender cómo el bot procesa la información necesaria para proporcionar sus funciones.
